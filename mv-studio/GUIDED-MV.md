# Osmanthus 歌曲 MV 引导流程

入口：音乐作品的「创作 MV」，或 `/mv/director.html`。原自由画布在「精细编辑」中保留。

1. 自动带入选定的音频版本和已有歌词时间轴。
2. 选择连续歌词、时间范围或整首；重复歌词按演唱位置区分。没有可信时间轴时只提供时间选段与整首，不推算虚构的歌词时间。
3. 提供画面想法、画幅与可选参考图。规划结合歌词、音频响度变化和声学重音估计；这些不是经过人工验收的精确节拍或情绪分类。
4. 在同一页面审核角色、场景与分镜。无人物方案可以不生成角色。每个分镜可试听对应音乐。
5. 方案阶段先展示完成当前方案的图片、视频及合计预估，扣除可复用素材；再分别确认图片制作和视频制作。图片制作前同时检查两阶段本地额度，任一不足时保留方案，不开始付费媒体任务。以审核后的分镜图生成镜头并合成原曲，可烧录已有同步歌词。
6. 对话修改角色、场景、分镜或整体方向。关联失效只传播到受影响镜头；图片、视频依内容签名复用，旧版本保留。
7. 下载 MP4、使用系统分享或复制成片链接。链接沿用当前站点访问范围，不会自动建立公网托管。

## 工作台界面

- 引导创作、作品列表和精细编辑沿用音乐工作台的黑灰底色、白色主按钮、字体与原始 Logo；公共颜色集中在 `public/osmanthus-theme.css`。
- 侧栏可以返回音乐首页、音乐创作或 MV 列表；当前工程入口不会离开正在编辑的歌曲。
- 进入歌曲工程后，底部播放器持续保留。唱片随播放旋转，支持暂停、回到开头、拖动进度、音量与静音；分镜试听也控制同一个音频元素。成片视频与歌曲试听互斥，避免声音重叠。
- 选段、分镜、分享和修改弹窗支持窄屏滚动；费用预检与预算限制继续保留。界面改动不触发付费图片或视频生成。

## 工程与恢复

- `mv-director.mjs` 管理版本、任务、费用预检、图片/视频生成与合成。
- `public/mv-director-domain.js` 负责范围、分镜时间和影响关系校验。
- `GET /api/mv-director/:id/quote?kind=complete` 可在没有预览图时读取整段预估、可复用数量和分阶段额度；报价本身不生成媒体或修改工程。
- `public/director.html` 与 `public/mv-director.js` 提供三个阶段的界面。
- 数据保存在 `data/mv-director/`，不写入音频原件，也不覆盖旧画布。
- 每个工程绑定歌曲 SHA-256；重复请求、页面关闭、服务重启不会盲目重复提交已登记的付费任务。
- 不明确的文字模型请求保留待核对状态；媒体任务失败后可恢复原任务与本地合成。明确失败的供应商任务不会悄悄换 ID 重新付费。
- 「精细编辑」把当前图片和成片登记到原歌曲画布，已有节点保留，并提供返回方案入口。画布中的自由调整保存于画布，不会自动反写引导方案；引导方案的局部重生成仍从方案页面操作。

## 运行配置

沿用音乐和 MV 服务的现有启动方式。需要 FFmpeg / ffprobe；字幕使用系统字体并校验字形覆盖。生成服务使用现有 DeepSeek、千问图片和万相图生视频适配器，网页不接触密钥。

`MV_IMAGE_BUDGET_CNY` 默认 4 元，显式配置支持最高 200 元；`MV_VIDEO_BUDGET_CNY` 沿用现有视频预算配置。本次开发没有提高本机预算。预算是本地适配器账目，不替代供应商的余额、限额和账单，方案文字模型的 token 费用不计入图片/视频报价。

整首允许 2 秒至 10 分钟，镜头按乐句边界与声学线索组织，单镜生成长度按供应商整数秒要求上取整，再裁到歌曲时间轴。长歌曲可能超过当前测试余额，系统会在提交媒体请求前提示，不会自动截短、扣一部分费用后放弃剩余镜头。

## 验证口径

- 离线：选段、关联修改、幂等、重启、预算拒绝、原音频保护；真实 FFmpeg 合成 16 秒与 201.23 秒有声视频。模型使用可控测试响应，不能据此评价真实生成画质。
- 真实短片：验收记录保存在开发工作区 `research/mv-guided-flow-20261031/`。公开仓库不包含个人歌曲、模型生成素材、用户工程或密钥。
- 精确卡拍、跨镜人物一致性和完整歌曲的视觉叙事仍需用户试听/观看验收。技术链路通过不等于这些主观质量已经通过。
