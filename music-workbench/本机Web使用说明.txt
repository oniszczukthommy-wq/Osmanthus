Osmanthus 本机 Web 版

双击同目录的「启动Osmanthus.command」，等待就绪后会自动打开浏览器。
统一入口：http://127.0.0.1:8603/

1. 首页输入想法，创作歌曲；已有作品可以直接播放或进入 Studio。
2. Studio 中对话修改、手动开关轨道、调音量、查看歌词与乐谱、导出及分享。
3. 选择歌曲后点「创作 MV」，歌曲、歌词和当前混音会交给视频画布。
4. 画布可继续打开已有工程，生成分镜、镜头，剪辑并下载成片。

两端统一使用 Osmanthus 品牌和原 Logo，密钥只在服务端读取。
音乐端和视频端均运行在本机；关闭网页不等于停止服务。
没有增加注册、支付或公网部署。

终端操作（先进入本目录）：
  python3 tools/osmanthus_web.py start
  python3 tools/osmanthus_web.py status
  python3 tools/osmanthus_web.py stop

停止命令仅停止这个启动器启动的进程，不会停止此前独立运行的服务。
服务日志和启动记录位于 .local/osmanthus-web/，不包含 API Key。
视频源码位置：../ai video/mv-studio
如迁移位置，可设置 OSMANTHUS_MV_DIR 后启动。
