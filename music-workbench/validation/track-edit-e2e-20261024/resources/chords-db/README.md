# chords-db 吉他指型资源

来源：[tombatossals/chords-db](https://github.com/tombatossals/chords-db)。作者 David Rubert，MIT许可全文随目录 `LICENSE` 保存。

`guitar.json` 为2026-10-26隔离验证时读取的官方预构建数据，共377,917字节；本次复制的是该已验证快照，不是重新拉取可能已变化的master。SHA-256：

```text
cfe439962b2f444d2c341b1f0261403b4c3a3416e321147286fc608922699974
```

`source-receipt.json`保留原始下载时间、官方raw URL、字节数及许可哈希。未安装npm包或模型权重。

集成模块核对数据内MIDI与标准定弦/品位换算、手指/横按、音集、指定低音及本轮正品位跨度≤3。指型数据不分析原曲音频，也不保证木吉他自然听感；音乐接受范围由候选试听记录约束。
